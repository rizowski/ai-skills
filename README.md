# ai-skills

My skills for AI coding agents.

| Skill | What it does |
|---|---|
| [orchestrator](skills/orchestrator/SKILL.md) | Runs a Claude Code session as an orchestrator: it manages worker subagents against a priorities file and does no task work itself. |

## Install

Copy or link a skill folder into `~/.claude/skills/`:

```sh
ln -s "$PWD/skills/orchestrator" ~/.claude/skills/orchestrator
```
